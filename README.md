# deane 的个人全能工作台

> 单文件本地面板 · v1.8 · 双击即用，也可在线访问

统筹工作、学习、健康、理财与创作的一屏式个人仪表盘：**待办 / 学习 / 健康体重 / 财务 / 内容排期 / 习惯打卡 / 心情**，所有数据即时保存在浏览器 localStorage，刷新不丢、不联网、不上传。

## 本地使用

直接双击 `index.html` 即可运行（无需服务器、无外部依赖）。数据存于当前浏览器；换设备/清缓存前请先在「数据与备份」里导出 JSON 备份。

## 功能速览

- 待办：分类筛选、勾选完成、行内编辑/删除、搜索
- 学习：按周存档的进步趋势曲线（本周/上周/本月三档）
- 健康：体重记录与目标、近 7/30 天曲线、达成率
- 财务：记账、本月收支环图、明细
- 习惯：打卡月历、连续/最长连续统计、补记过去
- 其他：提醒、内容排期、笔记灵感、心情折线、AI 今日回顾（本地规则）
- 数据：导出/导入 JSON 备份、重置演示数据、登录门禁与改密
